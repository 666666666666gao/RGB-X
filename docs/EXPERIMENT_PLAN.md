# 实验计划（2026-10-02）

## 研究边界

- RGB-T、RGB-D、RGB-Event 三任务联合训练，一份权重用于三类任务。
- XTrack-B 保留原专家结构、损失和冻结策略，只改变训练更新规则。
- 先识别真正共享且可训练的参数。冻结参数不能作为更新冲突缓解的证据。
- SUTrack-B224 用于非 MoE 结构迁移，B384 在方法通过受控实验后执行。
- 不承诺候选方法有效；所有实验结果必须来自实际训练与正式评测。

设置 A 仅使用 LasHeR-train、DepthTrack-train、VisEvent-train。
FE108、COESOT 在设置 A 中仅作跨数据集测试，不加入训练。
设置 B 后续增加两个事件训练集，普通基线与新方法必须同时扩展。

## 三个主模块

### 一：定位结构感知的更新风险估计

检查候选实际位移 Delta，而不是用当前损失或梯度大小作为最终风险。
首版沿用已有响应/分类损失与框回归损失，每任务分别检查两个定位目标。
风险为正部：`(J(theta + Delta) - J(theta)) / (s + epsilon) - tau`。
尺度 s 与容忍 tau 只能由训练池确定，不能通过测试集选择。
一阶预测用于降低检查成本，周期性真实前后检查用于校准。
同一候选比较从同一模型、优化器、随机状态和检查批次出发。

### 二：定位风险驱动的任务自适应更新与选择性修正

正式纳入多任务自适应优化：为 T/D/E 共享参数分别维护任务累计统计，先生成任务自适应候选位移。
它借鉴 AdaTask，独立任务统计本身不能当作新贡献。
未检测到显著定位退化时保留此候选；检测到风险时，仅修正相关共享更新分量。
风险梯度的低维子空间、软约束与修正幅度限制是待验证的设计。
不以梯度量级均衡为最终目标，不对整个任务简单缩放学习率。
专用参数不强制协调，但全模型风险检查包含它们的实际变化。

### 三：预测框驱动的短轨迹验证

使用训练池 3—5 帧片段，从同一状态比较少量修正强度。
预测框决定下一帧搜索区域，检验漂移累积；不能每帧用真实框重新居中。
首版仅前向验收，不增加推理时网络，不要求短轨迹反向传播。
这些片段一旦参与更新选择就是训练信号，不能宣称为独立泛化验证集。

## 对照与消融

必做：普通 AdamW、固定任务采样与明确损失归一化的 AdamW、PCGrad、CAGrad、AdaTask。
补充 GradNorm；SRFT 适配必须匹配数据使用、训练预算和可训练参数。
优化器对照仍未实现或运行，不能填入推测指标。

纵向消融：仅自适应、总损失风险、定位结构化风险、梯度修正对实际位移修正、
选择性对始终修正、频率匹配的随机修正，以及单帧/真实框居中多帧/预测框闭环短轨迹。
所有配对使用同数据、初始化、配置、冻结范围、随机种子与预算口径。
多个种子在工程检查通过后开展，分别报告相同数据曝光量与相同计算预算的比较。
同时报告风险预测能力、实际损害率、典型漂移、前向次数、墙钟与显存。

## 执行顺序

1. 固定作者代码版本，核对数据分割与初始化，完成 XTrack-B 三任务实际批次检查。
2. 收紧采样与损失归一化，运行 AdamW/PCGrad/CAGrad/AdaTask 配对实验。
3. 实现并逐项验证三个模块，完成机制分析和消融。
4. SUTrack-B224 配对迁移，增加 FE108/COESOT；之后再决定 B384。
5. 空间问题解决后补齐 RGBT234 与 VOT-RGBD2022，才能宣称完成五核心评测。

每个正式运行记录代码提交、数据分割、种子、初始化 SHA256、参数范围、任务曝光量与实际成本。
长任务根据首次吞吐估算 ETA，接近有意义的里程碑时查询；持续监视间隔 240 秒。

## 证据边界

用户交接中的作者指标只作参考。XTrack-B DepthTrack 论文与 README 的 F/Pr 冲突保留，
不能未经实际官方权重评测擅自确定。SUTrack 原配方与三数据集配方必须区分。
SRTrack 已涉及小参数更新引起的目标损失响应，不能把更新前后损失变化本身作为创新。
候选差异是联合三任务的优化器状态、具体定位退化识别以及共享实际更新的选择性修正。
